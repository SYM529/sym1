# 售后政策 FAQ

## 退货

**Q：无理由退货期限是多久？**

自签收之日起 **7 天内**可无理由退货，需保持包装与配件完整。
飞行器激活后不支持无理由退货（有飞行记录即视为激活）。

**Q：质量问题退货期限呢？**

自签收之日起 **15 天内**出现非人为性能故障，可选择退货或换货。

## 保修

| 产品类别 | 保修期 |
| --- | --- |
| 无人机整机 | 12 个月 |
| 云台相机 | 12 个月 |
| 电池 | 6 个月 |
| 充电器与配件 | 3 个月 |

保修期内非人为故障免费维修；人为损坏（进水、摔机、私自拆机）不在免费范围。

**Q：维修需要多久？**

寄修周期一般为 **7-10 个工作日**，不含物流在途时间。
东部的用户可选上门取件，费用由公司承担。

## 换新

**Q：什么情况可以换新？**

- 签收 15 天内出现非人为性能故障
- 维修两次仍无法正常使用的（出具检测报告后直接换新）

**Q：换新的产品保修期怎么算？**

换新机重新计算保修期，从换新发货日开始。

## 价格保护

购买后 **30 天内**官方降价，可申请差价补偿，
以订单支付金额与当前售价的差额为准，最高补偿 500 元。
活动价（秒杀、百亿补贴）不参与价保。

## 维修网点

全国共有 32 家授权维修网点，覆盖 28 个城市。
官方维修中心仅设在北京、上海、深圳三地，支持 walk-in 服务。
