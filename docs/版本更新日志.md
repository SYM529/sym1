# 版本更新日志

## v2.3.0（2025-06-18）

### 新增

- 图片理解：上传图片可直接提问，支持与计算工具组合使用
- 文档问答：上传文档自动入库，回答附带引用来源
- 语义缓存：相同问题命中缓存，响应速度大幅提升

### 修复

- 修复退出登录后输入框被浏览器自动填充占住的问题
- 修复知识库列表在文档较多时无法搜索的问题

## v2.2.0（2025-03-02）

### 新增

- 会话侧边栏：历史会话保存、切换、删除
- 评测可视化看板
- 限流与并发治理

### 变更

- 会话保留时长从 30 分钟提升至 7 天
- 默认架构切换为 ReAct（实测优于多 Agent 图）

### 修复

- 修复流式回答中 Markdown 渲染破碎的问题
- 修复表格分块被切碎导致检索失败的问题

## v2.1.0（2024-12-15）

### 新增

- 知识库（RAG）：混合检索 + 精排 + 引用溯源
- 文档上传：支持 Markdown、PDF 等格式

### 修复

- 修复乘方运算被误当作异或导致计算失败的问题
- 修复精排阈值过高误杀正确答案的问题

## v2.0.0（2024-10-01）

- 首个对外发布版本
- 包含：Agent 对话、数学计算、联网搜索、SSE 流式输出
