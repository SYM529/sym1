# 故障排查手册

## 无法登录

**现象**：输入正确密码仍提示"用户名或密码错误"。

**排查步骤**：

1. 确认账号是否在数据库中：查 `users` 表
2. 确认 JWT_SECRET 未在启动后变更——密钥变更会使所有旧 token 失效
3. 密码哈希用的是 bcrypt，无法反查；忘记密码只能重置

## 对话无响应

**现象**：发送消息后长时间无流式输出。

| 可能原因 | 判断方法 | 处理 |
| --- | --- | --- |
| Redis 未启动 | `GET /` 返回 `redis: false` | 启动 redis 容器 |
| 并发占满 | 返回 503 | 调大 `AGENT_MAX_CONCURRENCY` |
| 触发限流 | 返回 429 + Retry-After | 等待窗口恢复 |
| 上游模型超时 | 返回超时错误 | 重试；持续出现则检查服务商状态 |

## 知识库检索不到内容

**现象**：明明上传了文档，问相关问题却说知识库里没有。

1. 确认上传后提示"文档已入库 N 个片段"，`N` 大于 0
2. 打开知识库面板，确认文档在列表中
3. 问法尽量贴近文档原文用词——纯口语改写可能低于相关分阈值
4. 若都不行，检查 `RAG_MIN_SCORE`（默认 0.002）是否被调得过高

## 文件上传失败

**现象**：上传返回 400。

| 错误信息 | 原因 |
| --- | --- |
| 不支持的文件类型 | 后缀不在白名单（见 README 格式表） |
| 文件过大 | 图片 10MB、文档 20MB 上限 |
| 文件内容为空 | 空文件 |

注意：返回 **413** 说明请求被 nginx 拦截，需要调大 `client_max_body_size`。

## 容器相关

**容器反复重启**：查看 `docker logs agent-backend`，常见原因是
`.env` 缺少必填项（如 `JWT_SECRET`），服务启动时校验失败会主动退出。

**磁盘占用持续增长**：`uploads/` 目录保存所有上传的源文件，
当前只有新增没有清理接口，需定期手动清理。
